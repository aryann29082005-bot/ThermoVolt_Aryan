# 📡 ESP32 IoT Monitoring System

## Overview

ESP32 IoT system sending sensor data to Arduino IoT Cloud.

## Sensors

-   DS18B20 (GPIO 5)
-   ADC Voltage (GPIO 34)
-   LED (GPIO 23)

## Variables

-   temperature
-   adcVoltage
-   current_mA
-   ledState

## Notes

-   Voltage max 3.3V
-   3 ohm used for current calculation
